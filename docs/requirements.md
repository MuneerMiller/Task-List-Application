# Project requirements

The brief for this project, from the IBM SkillsBuild Web Development Fundamentals course.

1. The user must be able to input a task.
2. The user must be able to add a task with the Enter key or by clicking a button.
3. The user's tasks must appear on the page in a structured way.
4. The user must be able to check off a task when it's completed.
5. The user must be shown an error message if they don't enter a task correctly.
6. The company's brand guidelines must be followed.
7. The page must be visually appealing and work on both desktop and mobile.
